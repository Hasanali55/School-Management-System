# School Management System

A full-featured School Management System built using HTML, CSS, JavaScript, PHP, and MySQL. This admin panel allows school administrators to manage students, teachers, classes, and sections efficiently through a clean and simple dashboard.

## Features

- Admin Dashboard with quick overview of total students, teachers, classes, and sections
- Student Management: add, edit, delete, and view student records
- Teacher Management: add, edit, delete, and view teacher records
- Class Management: create and manage classes
- Section Management: create and manage sections within classes
- User Management
- Profile Management
- Full CRUD functionality: save, edit, and delete operations work across all modules

## Technologies Used

Frontend: HTML, CSS, JavaScript
Backend: PHP
Database: MySQL

## How to Run Locally

1. Clone this repository
   git clone https://github.com/Hasanali55/School-Management-System.git

2. Move the project folder into your local server directory (for example, htdocs for XAMPP)
3. Create a MySQL database and import the provided SQL file
4. Update database connection details in the config file
5. Run the project via localhost/School-Management-System in your browser
